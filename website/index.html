Free and open source · Apache 2.0

Every signing key, certificate and secret your apps need, in one encrypted vault.

DevVault stores your .p8 keys, .p12 certificates, provisioning profiles, Android keystores, service-account JSON and API keys. It reads the key IDs, fingerprints and real expiry dates from each file and keeps the original file as it was. It syncs through a storage bucket you own. There is no DevVault server.

macOS 12+, signed and notarized. Linux x64. Windows, iPhone and Android builds aren't released yet.

Built for the files password managers handle badly

Facts from the file, not guesses

Import a keystore or certificate and DevVault shows what's inside: key ID, team, bundle ID, fingerprints and the real expiry date. Every value says where it came from. Nothing is defaulted or inferred.

Expiry before it bites

One list of everything that has expired or expires soon: certificates, provisioning profiles, service accounts. Reminders tell you ahead of time instead of during a release.

Your bucket, your data

Sync between devices through any S3-compatible bucket you control: Cloudflare R2, AWS S3, Backblaze B2 or MinIO. The provider only ever sees encrypted objects with random names.

Organised by app

Group credentials by organization, app, platform and environment, so the production Android keystore is never confused with staging. Search by name, key ID or fingerprint.

New

Let AI coding agents use secrets without seeing them

DevVault comes with an MCP server for Claude Code, Codex CLI, Cursor, Gemini CLI, VS Code, Windsurf and other agents. An agent can look through your vault, but a secret value leaves only after you approve it in DevVault's own window.

  • The agent tells you why it needs the secret and which values it wants.
  • Values can be written straight into a file or passed to a command as environment variables, so they never reach the model.
  • Allow once or for 15 minutes, per client. Deny is always one click.
  • You never type your master password into the agent.

AI agent access is macOS-only for now.

Security, in plain terms

End-to-end encrypted

Your master password (Argon2id) and a one-time recovery key each unlock a random vault key. Every item and file is encrypted with XChaCha20-Poly1305.

Open format, open source

The vault format is published with test vectors, and all the code is on GitHub under Apache 2.0, so you can check every claim on this page.

Honest about limits

Nobody can protect against malware on an unlocked device. DevVault reduces the risk with auto-lock and clipboard clearing, and says so instead of promising more.
