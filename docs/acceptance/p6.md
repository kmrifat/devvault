# P6 gate: updates

Gate (from `docs/PLAN.md` P6, ADR-0007): on each desktop OS, a
Release-signed build of version N with *Check for updates* on finds N+1
from a published release and updates in place (macOS, MSIX) or shows the
banner (zip, tarball, AppImage). With the setting unset or off there is
no request to GitHub. A feed signed with the wrong key is refused.

Each row says how it was checked and what is still open. "Pending" means
it hasn't been run, not that it failed.

## Still to do before calling P6 done

- Rows 6 and 8 need the signing keys and a published release. Row 8
  also checks whether DevVault restarts after a Windows update; if it
  doesn't, the strip should say "DevVault will close to update" before
  handing over.
- Row 1's network capture: run a Release build with the setting unset,
  unlock, and confirm no connection to `api.github.com` (for example
  with Little Snitch, or `nettop -p <pid>`).
- Row 11 needs the tap repository, the tokens and a `LICENSE`.
