# P0 gate: vault core on every platform

Gate (from `docs/PLAN.md`):
- round-trip tests pass on all 5 platforms;
- a password change rewrites only `vault.json`.

`integration_test/vault_roundtrip_test.dart` runs inside the real app with
libsodium compiled for each platform. It covers:
1. **Known answers:** Argon2id at the default parameters (64 MiB, ops 3,
   p 1), HKDF recovery KEK, the envelope byte layout and keyed BLAKE2b must
   equal the values Go's `golang.org/x/crypto` produces.
2. **Round-trip:**
   - create a vault, then add an item with an attachment;
   - change the password, and **assert that the only write was
     `vault.json`**;
   - the old password is refused; unlock with the new password; read the
     item and the attachment back byte for byte;
   - unlock with the recovery key typed back in.

Independently, `tools/vectorcheck` (Go) verifies the published vectors and
unlocks the committed mini-vault (`.github/workflows/vectors.yml`).

## Results

| Platform | Where | Result | Argon2id (64 MiB, ops 3) |
|---|---|---|---|
| macOS (Apple silicon, sandboxed app) | local, 2026-10-07 | ✅ pass | 227 ms |
| iOS simulator (iPhone 17 Pro) | local, 2026-10-07 | ✅ pass | 167 ms |
| Linux (ubuntu-latest) | CI `roundtrip.yml`, 2026-10-07 | ✅ pass | 80 ms |
| Windows (windows-latest) | CI `roundtrip.yml`, 2026-10-07 | ✅ pass | 163 ms |
| Android (API 34 emulator, x86_64) | CI `roundtrip.yml`, 2026-10-07 | ✅ pass | 612 ms |

**Gate: met.** All five platforms give Go's known answers and complete the
round-trip, and a password change writes only `vault.json` on each of
them.

Physical-device timings (low-end Android in particular, ADR-0003's 1.5 s
budget) are collected during P3 device testing.
