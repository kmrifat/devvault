# P3 gate: iOS and Android

Gate (from `docs/PLAN.md` P3-08):
- TestFlight and Play internal testing builds;
- a device matrix: iOS 15 and the latest iOS, Android API 24 and the
  latest Android;
- the same vault and password on all five platforms.

**Status: PENDING.** The pipeline is in place (`release.yml` › Store
build, `docs/release.md`), but the store accounts and real devices it
needs are the owner's. Nothing below has run on a device yet; the native
code has only been built (`flutter build apk`, `flutter build ios
--no-codesign`) and its Dart side tested with fakes.

## 3. Same password on all five platforms

The vault created on one platform unlocks with the same password on the
other four, and an edit made on each reaches the rest. The format part
of this is automated (P0-15, `roundtrip.yml`: Linux, Windows and an
Android emulator on every vault_core change, macOS and an iOS simulator
when dispatched by hand); the apps themselves are checked by hand:
