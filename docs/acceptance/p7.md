# P7 gate: sidebar, menus, readability

Gate (from `docs/PLAN.md` P7): on macOS, a new user can find New app, New
organization and New item without right-clicking; the sidebar reads
Organization › App › Item; context menus are the system's; nothing
clickable is under 24 × 24 pt; goldens for every frame touched are
updated on all three kits.

Each row says how it was checked and what is still open. "Pending" means
it hasn't been run, not that it failed.

## Not done, on purpose

- Fingerprints wrapping only at a colon (P7-02): it needs invisible break
  characters inside selectable text, which a hand-made copy would carry.
- The tags field is about 3 pt wider than the other fields on macOS
  (macos_ui's text field padding).
- Picking an app's colour on phones: phones show the picked colour; the
  picker is desktop only for now.
- Secure fields on phones still type `•`: bc_ui's text field can't set
  the character yet.
